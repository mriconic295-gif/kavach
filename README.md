# KAVACH Cybersecurity Website

React + Vite + Supabase.

## Run
```bash
npm install
cp .env.example .env
# add Supabase URL and publishable/anon key
npm run dev
```

## Database
Run `supabase/schema.sql` in Supabase SQL Editor. Create the admin user in Supabase Authentication > Users. Admin panel: `/admin`.

## Images
Founder: `public/assets/founder.jpg`. Team KAVACH: upload exactly `team-01.jpg` through `team-05.jpg`. Logo: `kavach-logo.png`.
